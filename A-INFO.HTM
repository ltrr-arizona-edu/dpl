Dear Dendrochronologist:

You may download here the most up-to-date versions of computer programs in the Dendrochronology Program Library and their descriptions.  Each program is in a separate compressed file.  Click on the file name to download it to your computer.  Once on your hard disk, the command to restore the compressed file (Program COFECHA, for example) is:

        pkunzip COFECHA

The file DOCUMENT.ZIP contains descriptions of the programs; the restored files have the program name plus .TXT

Below is a brief identification of each program and sample data file.
Write me with any questions, doubts or suggestions:  rholmes@dakotacom.net

                                                 Cordially, Richard L. Holmes

Programs / Programas:

AGECRV   Fit general site pith-age curve to measurements
         Acomodar curva calculada según edad, a series de mediciones

ARSTAN   Chronology development with statistical analysis
         Producción de cronologías con buen análisis estadístico

ARSTANL  Same as ARSTAN with capacity for 600 series, 12,000 years
         Igual a ARSTAN con capacidad de 600 series y 12.000 años

CASE     Convert column (casewise) data to compact format
         Convierte archivo de columnas a formato compacto

COFECHA  Dating & measurement quality control
         Control de calidad de fechado y medición

COF12K   Same as COFECHA for time spans to 12,000 years
         Igual a COFECHA con capacidad de 12.000 años

CRONOL   Chronologies, simple
         Producción de cronologías con poca estadística

DOSXMSF  Memory manager needed by all programs
         Todo programa hace uso de este programa para manejo de memoria

DOSXNT   Alternate memory manager needed by all programs
         Maneja memoria para otros programas en DOS-NT

DPL      Contains various routines
         Contiene diversas rutinas

EARLAT   Detrend series of earlywood and latewood measurements
         Elimina tendencia en mediciones de leño temprano y tardío

EDRM     Edit ring measurement files
         Edita archivos de medición de anillos

EVENT    Superposed Epoch Analysis
         Análisis de épocas superpuestas

EXTRAP   Fit curve and extrapolate to find expected growth
         Acomoda curva determinística y la extiende (pronóstica)

FHCONV   Convert D-Base file to Fire History format
         Convierte archivo en D-Base a formato para historia de incendios

FMT      Manipulate data, change format
         Manipulación de series de datos y cambio de formato

JOLTS    Detect surges and suppressions in tree growth
         Detección de repentinos aumentos y reducciones de crecimiento

OLDCORE  Earliest ring measurements of tree-ring series are saved
         Guarda mediciones de anillos más al interior del árbol

OUTBREAK Detect outbreaks of insect populations
         Detección de aumentos de población de insectos

PCA      Principal components analysis
         Análisis de componentes principales

RECPC    Reconstruct original variables from PCs & eigenvectors
         Reconstrucción de series a partir de componentes y autovectores

RESPO    Response & correlation functions
         Funciones de respuesta y de correlación con el clima

RMATSG   Correlation matrix of series by segments
         Matriz de correlaciones entre series por segmentos

SAMDEP   Sample depth more even over time
         Empareja número de muestras en una colección de series

SCATTER  Make scattergram for line printer
         Gráficas primitivas en ASCII para impresoras sencillas

SCRPLT   High-resolution plots on monitor screen
         Gráficas de alta resolución para el monitor

SCRSAV   Colorful screen saver
         Patrón animado a color para el monitor

SIGLOF   Significance of low-frequency variance
         Nivel de confianza en varianza de baja frecuencia

SPANFIRE Spatial analysis of fire occurrence
         Análisis espacial de frecuencia de incendios

SSA      Singular Spectrum Analysis
         Análisis de espectro singular

SSIZ     Effects of reduced sample size on fire history
         Efecto de reducción de muestreo sobre la historia de incendios

XTRLST   List extreme high & low values in time series
         Lista de valores extremos, altos y bajos, en series de tiempo

XTRMOD   Modify extreme high & low values in time series
         Modifica valores extremos, altos y bajos, en series de tiempo

YUX      Produce column (casewise) file
         Produce archivo para graficar, de series en columnas

                     Datos mensuales de temperatura

        PRECISIO.DTA Precision format
                     Formato «Precisión»
